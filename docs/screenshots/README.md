# Screenshots

Capture Marketplace screenshots from a real Moodle test site after the release candidate has been validated.

Recommended screenshots:

1. `01-template-selector-preview.png` — activity settings form with a selected template and compatibility preview.
2. `02-template-applied-feedback.png` — immediate post-application feedback above the preview.
3. `03-create-template.png` — template creation form showing selectable settings.
4. `04-manage-templates.png` — personal template management with activity type and stored settings.
5. `05-edit-template.png` — editing name, description, included settings, and values.
6. `06-mobile-layout.png` — responsive layout on a narrow viewport.

Guidelines:

- use test/demo data only;
- do not show student personal information;
- do not show passwords, tokens, private URLs, or institution secrets;
- use a clean Boost or Boost-derived theme unless a theme comparison is relevant;
- capture at a readable resolution without browser developer tools covering the interface.
