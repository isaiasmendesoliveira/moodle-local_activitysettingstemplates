# Security policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately to:

**Isaias Mendes de Oliveira**  
**isaiasmendes@gmail.com**

Include, when possible:

- affected Activity Settings Templates version;
- affected Moodle version;
- steps to reproduce;
- expected and observed behaviour;
- security impact;
- any relevant logs or screenshots with personal/sensitive data removed.

Please do **not** open a public GitHub issue for a security vulnerability before coordinated disclosure.
