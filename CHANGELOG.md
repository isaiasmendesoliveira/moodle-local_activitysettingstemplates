# Changelog

All notable public changes to **Activity Settings Templates** are documented in this file.

## 1.0.0 - 2026-09-08

Initial public release.

### Added

- Personal activity settings templates for teachers.
- Integration with the native Moodle activity settings form.
- Templates filtered by activity type.
- Creation of templates from already configured activities.
- Selective inclusion of reusable settings.
- Editing of template name, description, included settings, and stored values.
- Template management overview with activity type and localized stored values.
- Pre-application compatibility preview with applicable, attention, and unavailable states.
- Accessible visual status using colour, icon, and explanatory text together.
- Immediate contextual feedback after a template is applied.
- Safe two-pass application for dependent Moodle form controls.
- Curated teacher-facing settings for major Moodle core activity/resource modules.
- Conservative fallback support for third-party activity modules.
- Protection against copying content, files, dates, credentials, relational identifiers, calculated values, and learner-generated data.
- Moodle Privacy API support for personal template data.
- Responsive Bootstrap-based interface.
- English (`en`), Brazilian Portuguese (`pt_br`), and Spanish (`es`) language packs.
- PHPUnit coverage for the field registry.
- GitHub issue templates, pull-request template, development workflow, testing documentation, marketplace text, and multilingual project documentation.

### Compatibility

- Requires Moodle 4.5 or later.
- Declares support for Moodle 4.5 through Moodle 5.2.
